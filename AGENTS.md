## Commands
- Activate venv first: `source venv/bin/activate`
- `--offline` uses canned topic candidates instead of live RSS — it is NOT a full dry-run. It does NOT skip RAG (Tavily/Firecrawl), the LLM (aborts if unavailable), visuals (fal/Replicate), Pi TTS, or publish. Those each need their own flag or a mock: `--dummy-frames` (synthetic visuals, no fal/Replicate), `--till-upload` (no publish). The truly hermetic/no-network path is `tests/test_hermetic_e2e.py` (stub agents mock LLM/RAG/TTS/visuals/publisher).
- Real run without publishing: `python main.py --global --till-upload` (alias `--no-upload`)
- Production run (recommended for real publishes): `./run_production.sh` — **runs a pre-flight health check** (`healthcheck.py`: hermetic test suite with static integrity checks, env keys, ffmpeg/ffprobe, LLM availability, Pi audio-edge reachability, YouTube upload quota + competitor-demand budget, RAG fact-source keys, BGM + disk space) and **aborts before launch if any required check fails**; then syncs code to Pi, runs in background, logs to `logs/`, emails result. `--no-detach` blocks; `--skip-health-check` bypasses the gate; optional `--probe-llm`/`--probe-yt` do a real 1-token LLM call and token-refresh `channels.list`. Auto-resumes from latest `logs/state_*.json` checkpoint if a previous run didn't reach `PUBLISHED_SUCCESS`.
- Resume a specific run: `python main.py --resume <pipeline_id>` (reads `logs/state_<pipeline_id>.json`).
- Region-optimized cron scheduler: `./cron_publish.sh [--region india|global] [--dry-run]` — schedules up to TWO publishes/day (the cadence behind the $2,000/month goal), back-timing launch windows [11:00-12:20] and [13:30-14:30] UTC out of the measured ~1h50m runtime so the publish lands in a peak window. The MARKET/region itself is decided DYNAMICALLY inside the pipeline (fact_retriever via `region_intelligence`, see converged plan); `--region` only pins an explicit override. Guards: never duplicates a live run (pgrep + heartbeat), caps daily publishes (`CSVG_MAX_DAILY_PUBLISHES`, default 4), enforces a cooldown (`CSVG_CRON_COOLDOWN_MIN`, default 90). Installed in crontab at `20 11` and `50 13` UTC daily; all decisions/skips journal to `logs/cron_publish.log`. `run_production.sh` passes `--global`/`--india` through as an override and otherwise runs dynamic.
- **Storability gate + revenue-weighted dynamic region + semantic gates + seed suite + fail-fast TTS + nano-banana AI thumbnails** → see `docs/PIPELINE_CONVERGED_PLAN.md` (SHIPPED & VERIFIED).
- **Nano-banana AI thumbnails** (Google `gemini-2.5-flash-image`), gated by `CSVG_NANO_BANANA_THUMBNAILS=1` + `GEMINI_API_KEY` (images prefer billed Vertex). Design-diversity: thumbnails rotate deterministically across 7 layouts × 5 palettes × 2 text styles (derived from `pipeline_id`; force one layout for A/B via `CSVG_THUMBNAIL_VARIANT=reaction-face|hero-object|...`) so every video doesn't repeat the same "yellow text one side, face the other" pattern. The model is instructed to render **NO text** — the bold hook is burned as crisp Studio-grade typography by `add_thumbnail_text` (legibility scrim + thick outline + accent bar), because image models render text badly. `generate_image` requests 2K output (`CSVG_NANO_BANANA_IMAGE_SIZE`; 1K/2K/4K), and the compliance pass (`comply_thumbnail`) enforces exact dims (1280x720/1080x1920), a target-driven brightness lift (~mean_lum≥100 so thumbs pop in the feed), an unsharp-mask sharpen after resize, and JPEG ≤2MB. **A/B variant set:** opt in with `CSVG_THUMBNAIL_VARIANTS=1` to also emit 3 Test-&-Compare variants (emotion-led / hero-object / text-led) + a `thumbnail_variants.json` manifest; the primary is uploaded live, the rest finish the experiment in YouTube Studio. Regular video: baked 16:9 image uploaded via `thumbnails.set` at publish (**works**). Shorts: baked 9:16 cover **prepended as the first frame** (thumbnails.set is ignored for Shorts — Google Issue #381127084). Standalone tools: `python run_nano_banana_link.py <url> --aspect both [--apply]` (analyze link: OAuth transcript + frame → thumbnail), `python run_channel_shorts_thumbnails.py --upload --skip-generated` (all channel Shorts), `python run_bake_shorts_covers.py` (bake cover into existing Short's first frame; requires re-upload — don't retro-bake published videos). Capable via OAuth caption transcripts requires `youtube.force-ssl` (re-run `get_youtube_token.py` to grant it).

## Post-publish growth (vidIQ playbook)
- **Themed playback playlists (reuse — never duplicate)**: every publish chains the video into a SINGLE themed playlist matched to the topic's `audience_type` (`_OUTCOME_PLAYLISTS` in `publisher.py`), using titles that already exist on the channel: `investor`/`finance_edu`/`real_estate` → "Finance, Markets & Wealth Stories"; `tech`/`business`/`science`/`health` → "AI, Tech & Innovation Deep-Dives"; `space`/`history` → "Space, Cosmology & Economic History"; `general` → "Global Trends & Infotainment". `upsert_playlist_add_video` normalizes titles before matching so existing playlists are REUSED instead of minting duplicate/orphan masters each run. Set `YOUTUBE_PLAYLIST_TITLE` to override chaining to a single fixed title. The seed comment links the bingeable theme playlist. Gate: `YOUTUBE_AUTO_PLAYLIST=1` (default). Reconcile/dry-run helper: `python reconcile_playlists.py [--apply]`.
- **Analytics feedback loop** ("top growth drivers" / "hook retention"): `src/engine/analytics_feedback.py` pulls per-video `views`/`estimatedMinutesWatched`/`averageViewDuration`/`averageViewPercentage`/`subscribersGained` from the YouTube Analytics API v2 for both the long-form master and its published Shorts (correlated back to the topic via each run's `logs/state_*.json`), persists `logs/analytics_feedback.json`, and computes a normalized **niche signal**. `FactRetriever` applies it as a soft TOPSIS tie-break favouring audiences that historically convert (`get_audience_bias`). Refresh is rate-limited (default 6h, `CSVG_ANALYTICS_REFRESH_MIN_AGE_SEC`, max `CSVG_ANALYTICS_MAX_VIDEOS`) and triggers non-fatally in a background thread at publish; run manually/from cron via `python run_analytics_feedback.py [--force] [--max-videos N]`. Env gates: `CSVG_ANALYTICS_FEEDBACK=1` (default on). Requires the OAuth token to have the `youtubeAnalytics` scope (re-run `get_youtube_token.py`). Served via dashboard `/api/analytics`.

## Env & secrets

- LLM fallback chain: primary model -> `LLM_FALLBACK_MODEL` -> `LLM_FALLBACK_MODEL2`. There's NO template/boilerplate fallback — if the LLM is unavailable the run **aborts** rather than emit canned content.
- LLM default provider config lives in `.env` (`PREFERRED_LLM_PROVIDER`, `LLM_MODEL`, keys). Per-role model pins: `LLM_ROUTE_GENERATE` / `LLM_ROUTE_POLISH` / `LLM_ROUTE_REPAIR` / `LLM_ROUTE_CRITIC` / `LLM_ROUTE_COHERENCE` / `LLM_ROUTE_CLASSIFY` (whitelisted suffixes in `src/engine/llm_client.py._route_model`); unset ⇒ default `LLM_MODEL`.
- Internal throughline-coherence audit (Layer-2 off-topic graft guard): `ObserverAgent.audit_internal_coherence` (`src/agents/observer.py`) judges each sentence against the **rest of the script's own body** and flags foreign digressions for surgical, state_hash-enforced removal by the revision loop. Env gate `CSVG_COHERENCE_AUDIT=1` (default on); degrades to no-op if the LLM is unavailable or errors. Optional model pin: `LLM_ROUTE_COHERENCE=<model>`.
- Semantic-gate env: `USE_SEMANTIC_GATES=1`, `ALLOW_SOFT_APPROVAL=1`, `HF_HOME`/`TRANSFORMERS_CACHE` -> repo-local `.hf_cache/`. Heavy ML deps live in `requirements-master.txt` (master ONLY, never the Pi; the Pi keeps TF-IDF fallback).
- Nano-banana thumbnail env: `CSVG_NANO_BANANA_THUMBNAILS=1` (default on) + `GEMINI_API_KEY`; `CSVG_NANO_BANANA_IMAGE_SIZE` (2K default); `CSVG_THUMBNAIL_VARIANT` (force one design layout for A/B). Images route through Vertex (`GOOGLE_CLOUD_PROJECT`) when set else the AI-Studio key. OAuth caption transcripts (`fetch_caption_transcript_oauth`) need a token containing `youtube.force-ssl`.
- Seed-comment + subscribe: `YOUTUBE_SUBSCRIBE_URL` (default `https://www.youtube.com/@lumenloop-ai?sub_confirmation=1`) is baked into every pinned seed comment; `YOUTUBE_PLAYLIST_TITLE` (default empty → theme-matched playlist) overrides playlist chaining to one fixed title.
- BGM pacing/levels (`mcp_servers/media_cloud/server.py` ffmpeg renderer + moviepy fallback): `BGM_TEMPO` (default 1.1, clamped 0.5-2.0), plus `BGM_VOLUME`/`BGM_SIDECHAIN_THRESHOLD`/`BGM_SIDECHAIN_RATIO` for the sidechain duck. ## Narrow tool-topic synthesis (fact_retriever stage 1b)
- `src/engine/tool_topic_synthesizer.py` + `fact_retriever.py`: after RSS ingestion, an LLM pass over the day's fresh corpus proposes narrow, evergreen, search-demand topics RSS news never surfaces — `"[Tool A] vs [Tool B] for [task]"`, `"How to [task] using [AI tool]"`, individual tool deep-dives, enterprise/developer tooling comparisons. Toggle: `TOOL_TOPIC_SYNTHESIS=1` (default on), count `TOOL_TOPIC_MAX` (default 4).

Kept synthetics enter TOPSIS first (evergreen > news), budget-bounded by `YT_SEARCH_DAILY_BUDGET`.
