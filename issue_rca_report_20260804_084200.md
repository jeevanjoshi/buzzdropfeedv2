# RCA & Fix Suggestions: YouTube Video Sync Drift & AI Slop
**Timestamp:** 2026-08-04T08:42:00+05:30

This report outlines the root causes and specific suggestions to resolve the subtitle drift and RAG slop issues on both the Raspberry Pi 5 (where the audio edge server runs) and the OCI instance.

---

## 1. Subtitle & Speech Sync Drift
### Analysis
* **Working Directory Asset Mismatch:** The audio edge server (`mcp_servers/audio_edge/server.py`) checks for `kokoro-v0.19.onnx` and `voices.bin` using relative paths (`"kokoro-v0.19.onnx"`). If the server is started from a different working directory (e.g. via a systemd unit or subdirectory), it fails to find the model and falls back to a 3-second beep WAV file.
* **Whisper Timings Desync:** Transcribing a 3-second beep WAV file fails to generate valid word timings. When the visuals run for the full script duration (50s) while the audio runs for 3s, the entire video timeline and subtitle synchronization drift.

### Suggested Fix
Update the path resolution in `mcp_servers/audio_edge/server.py` to use absolute paths relative to the script directory:
```python
base_dir = os.path.abspath(os.path.join(os.path.dirname(__file__), "../.."))
kokoro_path = os.path.join(base_dir, "kokoro-v0.19.onnx")
voices_path = os.path.join(base_dir, "voices.bin")
```

## 2. "AI Slop" & Tangent Injections
### Analysis
* **llama.cpp Script Timeout:** The local llama.cpp server takes longer than 60 seconds to generate a full 15-shot Infotainment script on CPU. Since the default timeout in `llm_client.py` is `60` seconds, it raises a `Read timed out` exception.
* **Naive Script Template Fallback:** When the LLM connection fails or times out, the pipeline falls back to the hardcoded `acts_blueprint` template. This template populates narration text by directly stitching raw snippets fetched from DuckDuckGo by the RAG retriever.
* **Noisy search snippets:** The RAG retriever passes the entire raw, verbose video headline to DuckDuckGo, fetching snippets containing sidebar recommendations and off-topic advertisements (e.g., *"Top 10 AI Tools in 2026"*, *"ChatGPT free traffic"*, *"LimeWire AI Studio"*).

### Suggested Fixes
1. **Increase Timeout:** Increase the `LLAMA_CPP_TIMEOUT` default to `300` in the OCI `.env` file to allow the local model to complete script generation.
2. **Add a RAG Ingestion Filter:** Add a regex keyword blacklist inside `src/engine/rag_retriever.py` to filter out promotional terms from DuckDuckGo snippets:
   ```python
   blacklist_patterns = [
       r"\bfree traffic\b", r"\bchat\s?gpt traffic\b", r"\blimewire\b", r"\bpricing\b",
       r"\bsign up\b", r"\baffiliate\b", r"\btop 10 ai\b", r"\bai content generator\b",
       r"\bai writer\b", r"\blife easier\b"
   ]
   ```
